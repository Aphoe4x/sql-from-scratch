sql-from-scratch

A SQL database written from scratch — no dependencies, no external services, running on plain Node.js.

A real storage engine — lexer, parser, B-tree storage, a planner with real cost estimates, a WAL that survives SIGKILL mid-write, and a CLI — all written from zero and runnable on disk today. Nothing is hosted or simulated; the database files are real files on your disk.

What it is

FileManager

Real 4096-byte pages on disk, page checksums, page freelist, WAL (write-ahead log) + commit protocol.

B-tree

Classic bottom-up B-tree over the pages: find, insert, delete, update, scan, stats.

SQL engine

Facade with execSql/execSelect/execUnion — create, insert (incl. multi-row, INSERT…SELECT), update, delete, DDL, DML.

Lexer + parser

Hand-written SQL subset parser — WHERE/OR, aggregates, joins, indexes, UNION, LIKE, ALTER TABLE, CREATE TABLE AS SELECT, TRUNCATE, VACUUM.

Planner

Static planner with real cost estimates: full-scan, index-seek, secondary-index-seek, index-nested-loop-join, union.

Smoke tests

22 suites covering the engine, DML, aggregates, joins, freelist, crash recovery, and more — all green.

Try it in 5 minutes
$ git clone https://github.com/Aphoe4x/sql-from-scratch
$ cd sql-from-scratch
$ npm i            # no dependencies, Node.js 24+ required
$ npm test         # 22 smoke suites pass
$ npm run demo     # seeds 1000 users, runs 3 SELECTs with planner output
$ npm run cli      # interactive shell — try `SELECT amount * 2 FROM users LIMIT 3;`
